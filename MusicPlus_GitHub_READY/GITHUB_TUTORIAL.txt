# Music+ — GitHub сборка EXE + APK

Этот проект уже содержит workflow-файлы для GitHub Actions.

## 1. Создай репозиторий

1. Открой https://github.com/
2. Нажми `+` → `New repository`.
3. Название: `MusicPlus`
4. Нажми `Create repository`.

## 2. Загрузить файлы

На странице репозитория:
`Add file` → `Upload files`.

Распакуй этот ZIP и перетащи ВСЁ содержимое папки проекта.
Особенно проверь, что в репозитории появились:

`.github/workflows/build-windows.yml`
`.github/workflows/build-android.yml`

Нажми `Commit changes`.

## 3. Собрать EXE

1. Открой вкладку `Actions`.
2. Слева выбери `Build Windows EXE`.
3. Нажми `Run workflow`.
4. Открой появившийся запуск.
5. Дождись зелёной галочки.
6. Внизу страницы открой `Artifacts`.
7. Скачай `MusicPlus-Windows-EXE`.

Внутри будет `MusicPlus.exe`.

## 4. Собрать APK

1. В `Actions` выбери `Build Android APK`.
2. Нажми `Run workflow`.
3. Дождись зелёной галочки.
4. Внизу открой `Artifacts`.
5. Скачай `MusicPlus-Android-APK`.

Внутри будет APK.

## Если сборка красная

Открой failed job и пришли скриншот красной ошибки.
По одному скриншоту можно определить, на каком шаге остановилась сборка.

## Важно

Приложение не содержит каталог Spotify и не скачивает песни Spotify.
Используй собственную музыку или музыку, на которую у тебя есть права.
