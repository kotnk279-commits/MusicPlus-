MUSIC+ — БЕЛЫЙ БЕСПЛАТНЫЙ МУЗЫКАЛЬНЫЙ ПЛЕЕР
================================================

В проекте использованы загруженные пользователем:
- logo.gif — второе изображение (анимированный логотип)
- wallpaper.jpg — третье изображение (фон)
Интерфейс сделан в светлой/белой стилистике по первому изображению.

Есть:
- плавная загрузка 0.0% -> 100.0%;
- логотип появляется издалека и увеличивается к центру;
- полупрозрачный белый фон и белая рамка загрузочного блока;
- часы МСК;
- локальная музыка;
- поиск по добавленным трекам;
- play/pause/next/previous;
- фоновое воспроизведение насколько это разрешает ОС/устройство.

ANDROID:
Открой Android в Linux/WSL:
  pip install buildozer cython
  buildozer android debug
APK будет в Android/bin/.

WINDOWS:
Открой Windows на Windows:
  build_exe.bat
EXE будет в Windows/dist/.

ВАЖНО:
В ZIP НЕ включены песни или плейлисты из Spotify. Каталог Spotify и их аудиозаписи являются чужим защищённым контентом, и я не могу распространять их копии.
Приложение рассчитано на ваши собственные/лицензированные аудиофайлы. Можно добавить много треков через "Добавить музыку".
